# 모아 — 추가 AI 비용 없는 콘텐츠 작업실

ChatGPT Pro에서 정리하고 생성한 콘텐츠를 구글 드라이브에서 가져와 두 계정별로 관리하는 개인용 웹앱입니다. 이 사이트는 유료 AI 생성 API를 호출하지 않습니다. 예전 키가 서버에 있어도 `/generate`는 403으로 차단합니다.

## 실행

Python 3.12 이상. 외부 패키지 설치는 없습니다.

```sh
cd /workspace/vacation-calendar
python3 server.py
```

기본 서버 주소는 `127.0.0.1:8000`. `PORT`로 변경할 수 있습니다. 반드시 `server.py`를 실행하세요. 이 앱에는 로그인·사용자 격리가 없으므로 공개 인터넷에 배포하지 마세요. OAuth 테스트를 위해 다른 주소에서 사용할 때는 먼저 접근 제어·HTTPS·영구 저장소를 구성해야 합니다.

## 가장 적게 작업하는 흐름

1. ChatGPT Pro에서 대본·캡션·이미지를 만듭니다. 현재 구독의 사용 제한이 적용됩니다.
2. 드라이브의 콘텐츠별 하위 폴더에 문서·이미지를 함께 보관합니다.
3. 사이트에서 ‘동기화’를 누릅니다. 브라우저로 다시 다운로드·업로드하지 않고 서버가 가져옵니다.
4. 사이트에서는 게시 일정·작업 상태·성과를 기록합니다.

기본 폴더: `https://drive.google.com/drive/folders/1Xze-MFZpmFKE6nP2UhVFv4whrdDK-ZLy`

```text
콘텐츠 작업실/
  계정 A/
    콘텐츠001/  ← 문서와 이미지 = 콘텐츠 한 건
    콘텐츠002/
  계정 B/
    콘텐츠003/
```

연결 설정에 계정 A 폴더와 대상 계정을 지정해 동기화하고, 계정 B 폴더로 바꿔 동기화합니다. 이미 가져온 콘텐츠의 계정은 이후 동기화에서 임의 변경하지 않습니다. 계정별 자동 폴더 매핑과 주기적 자동 동기화는 아직 없습니다.

Google Docs는 텍스트로 내보내서, TXT·MD·JSON은 UTF-8 텍스트로, PNG·JPG·WebP는 원본 파일로 가져옵니다. JSON은 일반 텍스트이며 구조화된 JSON 해석은 하지 않습니다. Google Docs에 삽입된 그림을 추출하지는 않으므로 이미지 파일도 폴더에 별도로 보관하세요. PDF·Word·영상·바로가기는 건너뜁니다.

폴더당 최대 이미지 20개, 이미지당 15MB, 문서 파일당 100KB, 합산 문서 100,000자, 한 번에 하위 폴더 100개·파일 1,000개까지 지원합니다. 목록은 페이지를 끝까지 읽으며 한도를 넘으면 오류를 표시합니다. 여러 폴더 동기화 도중 오류가 나면 앞서 완료된 폴더는 저장됩니다. 재시도하면 이미 저장된 파일은 중복 생성하지 않습니다.

같은 폴더는 같은 콘텐츠로 갱신하며 파일 ID·수정 시간으로 변경을 감지합니다. 사이트에서 대본·캡션·제목·프롬프트를 편집했다면 그 수정본을 유지하고 최신 드라이브 원문은 별도로 보여줍니다. 원문을 검토한 후 필요한 부분을 직접 적용하세요. 원격 삭제는 로컬 콘텐츠나 이미지를 자동 삭제하지 않습니다. 사이트에서 삭제한 드라이브 콘텐츠는 다음 동기화에서 다시 가져옵니다. 같은 ID의 이미지가 바뀌면 해당 이미지의 로컬 사본을 교체합니다.

문서에 다음 양식을 사용하면 자동 분류됩니다. 원문도 함께 보관합니다.

```text
제목: 콘텐츠 제목
캡션: 게시할 글
해시태그: #태그
대본: 카드별 문구 또는 릴스 대본
이미지 생성 지시: 다음에 ChatGPT에서 사용할 지시
```

## 구글 드라이브 연결 — 일회성 설정

현재 플랫폼에 구글 드라이브 로그인 도구나 유효한 연결 자격이 제공되지 않았습니다. 공유 링크만 저장했다고 연결이 성립하는 것은 아닙니다. 공식 Drive API를 통한 비공개 폴더 가져오기를 구현했습니다. 공개 폴더 HTML을 스크래핑하거나 공유 권한을 자동 변경하지 않습니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들거나 기존 프로젝트를 선택합니다.
2. Google Drive API를 사용 설정합니다. 이 앱에 유료 AI 결제는 필요 없습니다. 드라이브 저장 용량·API 할당량 등 구글 계정의 기존 제한은 적용됩니다.
3. Google Auth Platform의 브랜딩·대상·데이터 액세스를 설정하고 개인용 테스트 사용자로 본인 계정을 추가합니다. 요청 범위는 `https://www.googleapis.com/auth/drive.readonly`입니다. 앱은 지정 폴더만 가져오지만 OAuth 권한 자체는 드라이브 읽기 전체입니다.
4. 웹 애플리케이션용 OAuth 클라이언트를 만듭니다. 승인된 리디렉션 URI에 `http://127.0.0.1:8000/api/drive/callback`을 넣습니다. 다른 배포 주소라면 그 주소의 `/api/drive/callback`을 등록하고 아래 서버 설정도 맞춥니다. 등록한 주소는 사용자의 브라우저에서도 접근 가능해야 합니다.
5. 다음 값을 서버에 안전하게 주입합니다. 비밀번호는 채팅·GitHub·브라우저 프런트 코드에 넣지 마세요.
   - `GOOGLE_DRIVE_CLIENT_ID`: 클라이언트 ID
   - `GOOGLE_DRIVE_CLIENT_SECRET`: 클라이언트 비밀번호
   - `GOOGLE_DRIVE_REDIRECT_URI`: 기본 주소와 다를 때만 지정
6. 서버를 다시 시작하고 사이트의 ‘연결 설정 → 구글 계정 연결’에서 승인합니다.
7. 연결할 폴더와 계정을 저장한 뒤 ‘동기화’를 누릅니다.

테스트 모드인 외부 OAuth 앱은 구글 정책에 따라 주기적으로 재인증해야 할 수 있습니다. 외부 공개 서비스로 만들 때는 구글 OAuth 검토 등 별도 준비가 필요합니다.

클라우드 네트워크는 `www.googleapis.com`, `oauth2.googleapis.com` 접근이 필요합니다. 로그인 브라우저는 `accounts.google.com`에 접근해야 하며, 공유 폴더 직접 확인은 `drive.google.com`, Docs·파일 다운로드 환경에 따라 `docs.google.com`, `drive.usercontent.google.com`도 필요합니다. 차단 시 환경 설정에서 허용해야 하며 프록시·TLS 검증을 우회하지 마세요. 저장된 초안은 실행 환경에 즉시 적용되지 않습니다.

연결 해제는 서버의 토큰을 지우고 가져온 콘텐츠는 유지합니다. 구글 계정의 앱 권한 자체를 철회하려면 [구글 계정 연결 관리](https://myaccount.google.com/connections)를 사용하세요. 토큰은 `.studio/drive-token.json`에 0600 권한으로 저장하며 ZIP 백업에서 제외합니다. OAuth에는 상태 토큰·PKCE·만료 검사와 액세스 토큰 갱신을 사용합니다. 로그에는 인증 코드가 담긴 쿼리를 기록하지 않습니다.

## 연결 없이도 사용 가능

채팅 결과 붙여넣기와 이미지 드래그·클립보드 붙여넣기·파일 업로드가 가능합니다. 브라우저가 실제 이미지 복사를 지원해야 붙여넣을 수 있습니다. ChatGPT 이미지 자동 저장·채팅 자동 읽기는 지원하지 않습니다. 사이트의 ChatGPT 링크는 새 창을 여는 기능이며 Pro 계정과 프로그램을 인증 연결하는 기능이 아닙니다.

## 저장·백업·현재 범위

- `.studio/studio.db`: 콘텐츠·계정 이름
- `.studio/images/`: 이미지
- `.studio/drive-config.json`: 연결 폴더·최근 동기화
- `.studio/drive-token.json`: 비공개 OAuth 토큰, 백업에서 제외
- `STUDIO_DATA_DIR`: 데이터 디렉터리 변경
- 전체 자료 백업: 콘텐츠 JSON과 이미지 ZIP. 토큰·OAuth 설정·클라이언트 비밀번호는 제외

데이터는 Git에 포함되지 않습니다. 이전하려면 서버를 멈추고 데이터 디렉터리 전체를 안전하게 옮기거나 백업 ZIP을 보관하세요. ZIP 복원 화면은 아직 없습니다. 콘텐츠·이미지 백업은 OAuth 연결의 복원이 아닙니다.

인스타그램 게시·통계 자동 수집과 드라이브로의 양방향 업로드는 연결하지 않았습니다. 일정은 한국 시간 기준 기록용이며 자동 게시가 아닙니다. 성과는 수동 입력합니다. 유료 AI 생성 코드와 UI를 제거했으며 Pro 구독은 사이트 API 비용으로 전환되지 않습니다.

예전에 저장한 환경 초안의 `CONTENT_STUDIO_API_KEY` 요구사항은 더 이상 사용하지 않습니다. 환경 설정에서 해당 요구사항을 제거해도 됩니다. 앱에는 키가 전혀 필요 없습니다.

## 검증

```sh
python3 -m unittest discover -s tests -v
node --check app.js
```

테스트는 임시 데이터 디렉터리를 사용합니다. HTTP 저장·수정·이미지 업로드·백업·삭제, 유료 생성 403, Drive 페이지 처리·반복 동기화·로컬 편집 충돌 보존·OAuth 상태/PKCE·토큰 권한을 검증합니다. Google 응답은 테스트에서 대체하므로 실제 Google 연결 성공과 구분해야 합니다. 실제 접근 검증은 유효한 Google 연결과 적용된 네트워크 정책이 필요합니다.
