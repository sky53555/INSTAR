구글 드라이브 연결

추가 AI 사용료 없이 드라이브의 문서·이미지를 가져옵니다. 원본 파일은 수정하거나 삭제하지 않습니다.

콘텐츠별 하위 폴더에 문서와 이미지를 함께 넣어 주세요. 폴더마다 콘텐츠 1건으로 가져옵니다. 계정별 폴더를 바꿔가며 동기화할 수 있습니다.

처음 연결하는 방법
  1. Google Cloud Console에서 Drive API를 사용 설정합니다. 유료 AI 결제는 필요 없습니다.
  2. OAuth 동의 화면에서 개인용 테스트 사용자로 본인 계정을 등록합니다.
  3. 웹 애플리케이션용 OAuth 클라이언트를 만들고 아래 콜백 주소를 승인된 리디렉션 URI에 등록합니다.
  4. 클라이언트 ID와 비밀번호는 서버의 보안 설정에 등록합니다. 채팅이나 GitHub에 올리지 마세요.
  5. 설정을 적용한 뒤 ‘구글 계정 연결’을 누르고 읽기 권한을 승인합니다.

콜백 주소:

서버 설정: GOOGLE_DRIVE_CLIENT_ID, GOOGLE_DRIVE_CLIENT_SECRET, 필요 시 GOOGLE_DRIVE_REDIRECT_URI. 상세 내용은 README를 확인하세요.

이 앱은 드라이브 전체 읽기 권한을 요청하지만 가져오기는 지정 폴더와 하위 폴더만 실행합니다. 외부 공개 앱으로 배포할 때는 구글의 OAuth 검토가 필요할 수 있습니다.

Google Docs·TXT·MD·JSON과 PNG·JPG·WebP를 지원합니다. PDF·Word·영상은 가져오지 않습니다. 동기화는 버튼을 눌러 실행하며, 양방향 편집과 자동 업로드는 지원하지 않습니다.
